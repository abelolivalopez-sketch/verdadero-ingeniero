## Por qué un ingeniero necesita números "imaginarios"

Los números complejos no tienen nada de imaginario en ingeniería: son la herramienta natural para **todo lo que gira u oscila**: corriente alterna, vibraciones, control, acústica, aerodinámica potencial (la transformación de Joukowski convierte un círculo en un perfil de ala usando complejos). Hoy aprendemos a operar con ellos; mañana, a usarlos.

## Definición

La unidad imaginaria cumple \( i^2 = -1 \) (en electricidad se escribe **j** para no confundirla con la corriente). Un número complejo es

\[ z = a + b\,i \qquad a = \text{Re}(z),\quad b = \text{Im}(z) \]

Se representa como un punto (o vector) en el **plano complejo**: eje horizontal real, eje vertical imaginario.

Potencias de i: \( i^1 = i,\ i^2 = -1,\ i^3 = -i,\ i^4 = 1 \), y se repite cada 4.

## Forma binómica: sumas y productos

- Suma: \( (2 + 3i) + (1 - i) = 3 + 2i \)
- Producto (como polinomios, usando \(i^2 = -1\)):
\[ (3 + 4i)(1 - 2i) = 3 - 6i + 4i - 8i^2 = 11 - 2i \]
- **Conjugado:** \( \bar z = a - b\,i \). Cumple \( z\,\bar z = a^2 + b^2 \) (un número real).
- División: multiplica arriba y abajo por el conjugado del denominador:
\[ \frac{3 + 4i}{1 - 2i} = \frac{(3 + 4i)(1 + 2i)}{(1 - 2i)(1 + 2i)} = \frac{-5 + 10i}{5} = -1 + 2i \]

## Forma polar: módulo y argumento

\[ z = r\,\angle\theta \qquad r = |z| = \sqrt{a^2 + b^2},\qquad \theta = \arg z = \text{atan2}(b, a) \]

y de vuelta: \( a = r\cos\theta,\ b = r\sin\theta \).

**Ejemplo:** \( -1 + i \) tiene \( r = \sqrt2 \) y \( \theta = 135° \) (segundo cuadrante; arctan(−1) daría −45°, ¡error! Usa atan2).

## La fórmula de Euler

\[ e^{i\theta} = \cos\theta + i\sin\theta \]

Es una de las ecuaciones más importantes de la ingeniería. Permite escribir cualquier complejo como

\[ z = r\,e^{i\theta} \]

Caso famoso: \( e^{i\pi} = -1 \).

## Multiplicar y dividir en polar: girar y escalar

\[ z_1 z_2 = r_1 r_2\, e^{i(\theta_1 + \theta_2)} \qquad \frac{z_1}{z_2} = \frac{r_1}{r_2}\, e^{i(\theta_1 - \theta_2)} \]

**Multiplicar** = multiplicar módulos y **sumar ángulos**. Por eso multiplicar por \( i = e^{i\pi/2} \) **gira 90° antihorario** un vector. Esto es exactamente lo que hace una derivada sobre una sinusoide, como verás mañana.

**Ejemplo:** \( 2\angle30° \times 3\angle45° = 6\angle75° = 6\cos75° + 6i\sin75° = 1{,}553 + 5{,}796i \).

**Regla práctica:** suma y resta en binómica; producto, división y potencias en polar.

## Potencias y raíces (De Moivre)

\[ z^n = r^n e^{in\theta} \]

**Ejemplo:** \( (1 + i)^8 = (\sqrt2)^8 e^{i\,8\cdot45°} = 16\,e^{i\,360°} = 16 \).

Las **raíces n-ésimas** de z son n números repartidos uniformemente en un círculo:

\[ \sqrt[n]{z} = \sqrt[n]{r}\;\angle\frac{\theta + 360°k}{n},\quad k = 0, 1, \dots, n-1 \]

Las tres raíces cúbicas de 8 son \( 2\angle0°,\ 2\angle120°,\ 2\angle240° \): solo una es real.

En control automático, la estabilidad de un sistema depende de dónde caen en el plano complejo las raíces de un polinomio: si alguna tiene parte real positiva, el sistema es inestable. Lo verás en el módulo 20 (control).

## Taller (45 min): números complejos en Python y tu primer análisis de estabilidad

### 1. Python habla complejo
Python trae los complejos de serie: se escriben con **j** (`3 + 4j`) y el módulo `cmath` tiene todas las funciones.

```python
import cmath, math
import numpy as np

z = 3 + 4j
r, fase = cmath.polar(z)
print(f"z = {z} -> módulo {r}, argumento {math.degrees(fase):.2f}°")
print("De vuelta a binómica:", cmath.rect(2, math.radians(30)) * cmath.rect(3, math.radians(45)))
print("(1+1j)**8 =", (1 + 1j) ** 8)
print("Fórmula de Euler, e^(j·pi) =", cmath.exp(1j * math.pi))   # el 1e-16j es error de redondeo

# Raíces de polinomios: la clave de la estabilidad en control automático
for coefs in ([1, 2, 5], [1, 2, 3, 10]):
    polos = np.roots(coefs)
    estable = all(p.real < 0 for p in polos)
    print(f"Polinomio {coefs}: raíces {np.round(polos, 3)} -> {'ESTABLE' if estable else 'INESTABLE'}")
```

### 2. Qué significa lo que acabas de calcular
En el módulo de control verás que el comportamiento de un sistema (una suspensión, el control de un dron, un motor) depende de las **raíces de un polinomio** llamado ecuación característica:

- Raíz \( s = \sigma + j\omega \): la respuesta contiene \( e^{\sigma t}\cos(\omega t) \).
- Si **todas** tienen parte real negativa (\( \sigma < 0 \)), las oscilaciones se amortiguan: **estable**.
- Si **alguna** tiene parte real positiva, la respuesta crece sin límite: **inestable**.

Para \( s^2 + 2s + 5 \): raíces \( -1 \pm 2j \). Oscila a 2 rad/s y se amortigua con \( e^{-t} \). Estable.
Para \( s^3 + 2s^2 + 3s + 10 \): una raíz real −2,445 y dos complejas \( 0{,}223 \pm 2{,}010j \). Parte real positiva: inestable, aunque todos los coeficientes sean positivos.
